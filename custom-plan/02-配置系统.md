# 02 - 配置系统

## 设计原则

1. **沿用 `SOFT_SERVE_CONFIG_LOCATION`**: 配置文件路径
2. **`SOFT_SERVE_DATA_PATH` 保持 `data`**，FileStore 后端自动改为当前目录
3. **环境变量优先级高于配置文件**
4. **同时支持 YAML 和 JSON 格式**
5. **简化配置**：只保留必要的自定义选项

## 配置加载流程

```
┌─────────────────────────────────────────────────────────────────┐
│                       配置加载流程                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   1. 创建默认配置                                                │
│      │  DefaultConfig()                                         │
│      │  DataPath = "data" (保持向后兼容)                         │
│      ▼                                                          │
│   2. FileStore 覆盖 (仅 filestore 后端)                          │
│      │  如果 DataPath == "data" 且无环境变量                     │
│      │  则 DataPath = "." (当前目录)                             │
│      ▼                                                          │
│   3. 加载配置文件                                                │
│      │  优先级: SOFT_SERVE_CONFIG_LOCATION > {DATA_PATH}/config │
│      │  格式: YAML 或 JSON (根据文件扩展名)                      │
│      ▼                                                          │
│   4. 环境变量覆盖                                                │
│      │  SOFT_SERVE_* 环境变量                                   │
│      │  覆盖配置文件中的值                                       │
│      ▼                                                          │
│   5. 验证和规范化                                                │
│      │  路径展开 (~, 环境变量)                                   │
│      │  相对路径转绝对路径                                       │
│      ▼                                                          │
│   6. 最终配置                                                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 配置优先级

```
环境变量 > 配置文件 > 默认值
```

### 示例

```bash
# 配置文件: ./config.yaml
name: "Git Server"
ssh:
  listen_addr: ":2222"

# 环境变量
export SOFT_SERVE_SSH_LISTEN_ADDR=":3333"
export SOFT_SERVE_NAME="My Server"

# 最终配置:
# name: "My Server"        (环境变量覆盖)
# ssh.listen_addr: ":3333" (环境变量覆盖)
```

## 配置文件位置

```
# 优先级从高到低

1. SOFT_SERVE_CONFIG_LOCATION 环境变量
   - SOFT_SERVE_CONFIG_LOCATION=/etc/soft-serve/config.yaml
   - SOFT_SERVE_CONFIG_LOCATION=./my-config.json

2. {DATA_PATH}/config.yaml 或 {DATA_PATH}/config.json
   - FileStore: 默认 ./config.yaml (当前目录)
   - DBStore: 默认 data/config.yaml
   - 如果同时存在 yaml 和 json，优先 yaml
```

## 配置结构

### 完整结构

```go
// pkg/config/config.go

type Config struct {
    // 服务器名称
    Name string `env:"NAME" yaml:"name" json:"name"`

    // 用户目录路径 (仅 filestore 后端)
    UsersPath string `env:"USERS_PATH" yaml:"users_path" json:"users_path"`

    // SSH 配置
    SSH SSHConfig `envPrefix:"SSH_" yaml:"ssh" json:"ssh"`

    // HTTP 配置
    HTTP HTTPConfig `envPrefix:"HTTP_" yaml:"http" json:"http"`

    // Git 配置
    Git GitConfig `envPrefix:"GIT_" yaml:"git" json:"git"`

    // Stats 配置
    Stats StatsConfig `envPrefix:"STATS_" yaml:"stats" json:"stats"`

    // 日志配置
    Log LogConfig `envPrefix:"LOG_" yaml:"log" json:"log"`

    // 数据库配置 (仅 dbstore 后端)
    DB DBConfig `envPrefix:"DB_" yaml:"db" json:"db"`

    // LFS 配置
    LFS LFSConfig `envPrefix:"LFS_" yaml:"lfs" json:"lfs"`

    // Jobs 配置
    Jobs JobsConfig `envPrefix:"JOBS_" yaml:"jobs" json:"jobs"`

    // 初始管理员公钥
    InitialAdminKeys []string `env:"INITIAL_ADMIN_KEYS" yaml:"initial_admin_keys" json:"initial_admin_keys"`

    // 数据路径 (非配置文件字段)
    DataPath string `env:"DATA_PATH" yaml:"-" json:"-"`
}
```

### 固定路径 (不可配置)

| 路径 | 默认值 | 说明 |
|------|--------|------|
| SSH 密钥 | `{DATA_PATH}/ssh` | 服务器主机密钥 |
| 日志 | `{DATA_PATH}/log` | 日志文件 |
| LFS | `{DATA_PATH}/.lfs` | LFS 对象存储 |
| Admin 公钥 | `~/.ssh` | 管理员认证公钥 |

### 可配置路径

| 路径 | 配置项 | 环境变量 | 默认值 |
|------|--------|----------|--------|
| 用户目录 | `users_path` | `SOFT_SERVE_USERS_PATH` | `{DATA_PATH}/users` |

## 配置文件示例

### YAML 格式

```yaml
# config.yaml

# 服务器名称
name: My Git Server

# 用户目录 (可选，默认 {DATA_PATH}/users)
users_path: ./users

# SSH 配置
ssh:
  enabled: true
  listen_addr: :23231
  public_url: ssh://localhost:23231

# HTTP 配置
http:
  enabled: true
  listen_addr: :23232
  public_url: http://localhost:23232

# Git 配置
git:
  enabled: true
  listen_addr: :9418

# LFS 配置
lfs:
  enabled: true
  ssh_enabled: false

# 日志配置
log:
  format: text
  time_format: "2006-01-02 15:04:05"
```

### JSON 格式

```json
{
  "name": "My Git Server",

  "ssh": {

    "public_url": "ssh://localhost:23231"
  },

    "enabled": true,
    "listen_addr": ":23232",
    "public_url": "http://localhost:23232"
  },

  }
}
```

## 关键修改

### DefaultDataPath (保持不变)

```go
// pkg/config/config.go

// DefaultDataPath 返回数据目录路径
// 优先使用 SOFT_SERVE_DATA_PATH 环境变量
// 默认为 "data" (保持向后兼容)
func DefaultDataPath() string {
    dp := os.Getenv("SOFT_SERVE_DATA_PATH")
    if dp == "" {
        dp = "data"  // 保持原值
    }
    return dp
}
```

### FileStore 覆盖默认路径

```go
// pkg/store/file/store_filestore.go

func NewStore(cfg *config.Config) (store.Store, error) {
    // FileStore 后端: 如果是默认值 "data"，改为当前目录
    if cfg.DataPath == "data" && os.Getenv("SOFT_SERVE_DATA_PATH") == "" {
        cfg.DataPath = "."
    }

    // 设置用户目录默认值
    if cfg.UsersPath == "" {
        cfg.UsersPath = filepath.Join(cfg.DataPath, "users")
    }

    fs := &FileStore{
        cfg:   cfg,
        users: make(map[string]*User),
        repos: make(map[string]*Repo),
    }
    // ...
}
```

### 固定路径处理

```go
// pkg/config/config.go

func (c *Config) Validate() error {
    // ... 其他验证

    // 固定路径 (基于 DataPath)
    sshPath := filepath.Join(c.DataPath, "ssh")
    logPath := filepath.Join(c.DataPath, "log")
    lfsPath := filepath.Join(c.DataPath, ".lfs")

    // Admin 公钥固定为 ~/.ssh
    home, _ := os.UserHomeDir()
    adminKeysPath := filepath.Join(home, ".ssh")

    // 创建必要目录
    for _, dir := range []string{sshPath, logPath, c.UsersPath} {
        if err := os.MkdirAll(dir, 0755); err != nil {
            return err
        }
    }

    return nil
}
```

### 配置文件路径

```go
// pkg/config/config.go

func (c *Config) ConfigPath() string {
    // 1. 环境变量指定
    if path := os.Getenv("SOFT_SERVE_CONFIG_LOCATION"); exist(path) {
        return path
    }

    // 2. 默认在数据目录下查找
    // 优先 yaml，其次 json
    yamlPath := filepath.Join(c.DataPath, "config.yaml")
    if exist(yamlPath) {
        return yamlPath
    }

    jsonPath := filepath.Join(c.DataPath, "config.json")
    if exist(jsonPath) {
        return jsonPath
    }

    // 3. 返回默认路径 (用于创建)
    return yamlPath
}
```

## 简化后的环境变量

### 核心变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_CONFIG_LOCATION` | 配置文件路径 | `{DATA_PATH}/config.yaml` |
| `SOFT_SERVE_DATA_PATH` | 数据目录 | `data` (filestore 改为 `.`) |

### 新增变量 (仅 filestore)

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_USERS_PATH` | 用户目录 | `{DATA_PATH}/users` |

│   └── soft-serve.log

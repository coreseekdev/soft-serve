# 10 - 聊天功能 (Chat)

## 概述

基于现有 SSH 结构，添加类似 IRC 的聊天机制。用户通过 SSH 公钥认证后，使用 `/chat` 命令进入聊天模式。

## 需求确认

| 需求项 | 决定 |
|--------|------|
| 身份认证 | 使用现有 SSH 公钥认证 |
| 消息持久化 | 持久化到文件系统（JSONL 格式） |
| 频道持久化 | 持久化到文件系统（JSONL 格式，追加写入） |
| 历史查询 | 默认 7 天，支持时间范围参数 |
| 频道管理 | 混合模式（默认 #general + 用户自建） |
| 界面形式 | 简单命令行 |
| 高级特性 | 仅 /topic 频道主题 |

## 设计约束（简化实现）

| 约束项 | 说明 |
|--------|------|
| 消息已读状态 | 不提供 |
| 消息 ID | 时间戳 + 流水号 |
| 频道 topic 权限 | 任何人都可设置 |
| 频道/消息删除 | 不支持，一旦写入不可删除 |
| 用户在线状态 | 不监控 |
| 消息撤回/编辑 | 不支持 |
| 事件与消息混合 | 刻意设计，便于回放完整历史 |

## 核心命令

```
# 进入聊天模式
> chat

# 频道管理
/join #channel        # 加入/创建频道
/leave #channel       # 离开频道
/channels             # 列出所有频道

# 切换当前目标
/select #general      # 切换到频道
/select @bob          # 切换到与 bob 的私聊

# 发送消息
hello                 # 发送到当前目标（频道或私聊）
#general hello        # 直接发送到 #general（不切换当前目标）

# 私聊（不切换当前目标）
/dm @bob hello        # 发送私聊给 bob

# 标记已读
/mark                 # 标记当前目标已读到最后一条
/mark #general        # 标记指定频道已读
/mark @bob            # 标记与 bob 的私聊已读

# 历史消息
/history              # 查看当前目标未读消息
/history --all        # 查看当前目标最近 7 天
/history #channel     # 查看指定频道历史
/history @bob         # 查看与 bob 的私聊历史
/history --from 2025-01-01 --to 2025-01-15  # 指定时间范围

# 频道信息
/topic #channel       # 查看频道主题
/topic #channel xxx   # 设置频道主题（任何人可设置）

# 其他
/who                  # 列出当前频道用户
/names #channel       # 列出指定频道用户
/whois @name          # 查看用户详细信息
/exit 或 Ctrl+D       # 退出聊天模式
```

## 邮箱模型

### 设计理念

- **频道邮箱** (`#channel.jsonl`): 存储频道消息和事件
- **用户邮箱** (`@user.jsonl`): 存储私聊、订阅、读取标记、状态快照
- **标记已读** = 给自己发一封包含 cursor 的邮件
- **状态快照** = 定期将当前状态打包，避免重建时回溯过多

### 用户邮箱消息类型

```go
// pkg/chat/message.go

type UserMessageType string

const (
    UserMsgDM       UserMessageType = "dm"       // 私聊消息
    UserMsgSub      UserMessageType = "sub"      // 订阅频道
    UserMsgUnsub    UserMessageType = "unsub"    // 取消订阅
    UserMsgMark     UserMessageType = "mark"     // 读取标记
    UserMsgSnapshot UserMessageType = "snapshot" // 状态快照
)

// 用户邮箱消息（统一结构）
type UserMessage struct {
    Type      UserMessageType `json:"type"`
    Timestamp time.Time       `json:"ts"`

    // dm 类型
    ID      string `json:"id,omitempty"`
    From    string `json:"from,omitempty"`
    Content string `json:"content,omitempty"`

    // sub/unsub/mark 类型
    Inbox  string `json:"inbox,omitempty"`  // 目标邮箱：#channel 或 @user
    Cursor string `json:"cursor,omitempty"` // 读取位置

    // snapshot 类型
    State *UserState `json:"state,omitempty"`
}

// 用户状态快照
type UserState struct {
    Subscriptions []Subscription `json:"subscriptions"`
}

type Subscription struct {
    Inbox  string `json:"inbox"`  // #channel 或 @user
    Cursor string `json:"cursor"` // 最后读取位置
}
```

### 状态重建

```go
// 从用户邮箱重建状态
func RebuildState(user string) (*UserState, error) {
    // 1. 找到最后一个 snapshot
    snapshot := FindLastSnapshot("@" + user)
    state := snapshot.State // 从快照开始

    // 2. 只处理快照之后的 sub/unsub/mark
    for _, msg := range ReadAfter("@"+user, snapshot.Timestamp) {
        switch msg.Type {
        case UserMsgSub:
            state.Subscriptions = append(state.Subscriptions, Subscription{
                Inbox: msg.Inbox, Cursor: "",
            })
        case UserMsgUnsub:
            state.Subscriptions = removeSub(state.Subscriptions, msg.Inbox)
        case UserMsgMark:
            updateCursor(state.Subscriptions, msg.Inbox, msg.Cursor)
        }
    }

    return state, nil
}
```

### 快照触发条件

| 触发条件 | 说明 |
|---------|------|
| 用户上线 | 如果距离上次快照超过 N 条记录 |
| 用户下线 | 保存最终状态 |
| 定时任务 | 每天凌晨为活跃用户生成快照 |
| 手动命令 | `/snapshot` 命令 |

```go
// 快照阈值
const SnapshotThreshold = 100 // 超过 100 条记录时触发快照

func MaybeSnapshot(user string) {
    lastSnapshot := FindLastSnapshot("@" + user)
    count := CountAfter("@"+user, lastSnapshot.Timestamp)

    if count > SnapshotThreshold {
        state := RebuildState(user)
        AppendToInbox("@"+user, UserMessage{
            Type:      UserMsgSnapshot,
            Timestamp: time.Now(),
            State:     state,
        })
    }
}
```

### 聊天用户 (ChatUser) - 内存结构

```go
// pkg/chat/user.go

type TargetType int

const (
    TargetTypeChannel TargetType = iota  // 频道
    TargetTypePrivate                    // 私聊
)

type ChatUser struct {
    Name         string          // 用户名（来自 SSH 认证）
    PublicKey    string          // 公钥指纹
    CurrentType  TargetType      // 当前目标类型
    CurrentCh    string          // 当前频道
    CurrentPeer  string          // 当前私聊对象
    State        *UserState      // 从邮箱重建的状态
    conn         *ssh.ServerConn
}

func (u *ChatUser) CurrentTarget() string {
    if u.CurrentType == TargetTypeChannel {
        return u.CurrentCh
    }
    return "@" + u.CurrentPeer
}

func (u *ChatUser) GetCursor(inbox string) string {
    for _, sub := range u.State.Subscriptions {
        if sub.Inbox == inbox {
            return sub.Cursor
        }
    }
    return ""
}
```

## 命令解析

```go
// pkg/chat/commands.go

type InputType int

const (
    InputTypeCommand InputType = iota  // /xxx 命令
    InputTypeChannel                   // #channel xxx 频道消息
    InputTypeMessage                   // xxx 当前目标消息
)

type ParsedInput struct {
    Type    InputType
    Target  string   // 目标：#channel（仅频道消息类型）
    Content string   // 消息内容
    Command string   // 命令名（仅命令类型）
    Args    []string // 命令参数
}

func ParseInput(input string) *ParsedInput {
    input = strings.TrimSpace(input)

    // 命令：/xxx
    if strings.HasPrefix(input, "/") {
        parts := strings.Fields(input[1:])
        return &ParsedInput{
            Type:    InputTypeCommand,
            Command: parts[0],
            Args:    parts[1:],
        }
    }

    // 频道消息：#channel xxx
    if strings.HasPrefix(input, "#") {
        parts := strings.SplitN(input[1:], " ", 2)
        if len(parts) == 2 {
            return &ParsedInput{
                Type:    InputTypeChannel,
                Target:  "#" + parts[0],
                Content: parts[1],
            }
        }
    }

    // 当前目标消息
    return &ParsedInput{
        Type:    InputTypeMessage,
        Content: input,
    }
}

// 命令处理映射
var commands = map[string]CommandHandler{
    "join":     handleJoin,
    "leave":    handleLeave,
    "select":   handleSelect,   // 切换当前目标
    "dm":       handleDM,       // 私聊命令
    "mark":     handleMark,     // 标记已读
    "history":  handleHistory,
    "topic":    handleTopic,
    "channels": handleChannels,
    "who":      handleWho,
    "names":    handleNames,
    "whois":    handleWhois,
    "exit":     handleExit,
    "quit":     handleExit,
}
```

## 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 并发消息写入 | 中 | 使用 sync.Mutex 保护文件写入 |
| 大量历史消息 | 低 | 默认查询 7 天，支持时间范围参数 |
| 断线重连 | 低 | 会话状态可丢弃，用户重新加入 |
| 存储格式兼容 | 中 | 使用 JSONL，版本化处理 |
| Members 快照一致 | 中 | join/leave 必记录；首条消息检查跨日补充 |
| 优雅关闭失败 | 中 | 监听信号，确保最终快照写入 |

## 优雅关闭

```go
// pkg/chat/chat.go

func (c *Chat) Shutdown(ctx context.Context) error {
    // 1. 停止接受新连接
    c.mu.Lock()
    c.shuttingDown = true
    c.mu.Unlock()

    // 2. 通知所有在线用户
    for _, sess := range c.sessions {
        sess.term.Write([]byte("\nServer is shutting down. Goodbye!\n"))
        close(sess.done)
    }

    // 3. 等待所有会话结束或超时
    done := make(chan struct{})
    go func() {
        for len(c.sessions) > 0 {
            time.Sleep(100 * time.Millisecond)
        }
        close(done)
    }()

    select {
    case <-done:
    case <-ctx.Done():
        // 超时，强制关闭
    }

    // 4. 为所有活跃频道记录最终 members 快照
    for name, ch := range c.channels {
        c.store.AppendChannelEvent(name, &ChannelEvent{
            Type:      ChannelEventMembers,
            Timestamp: time.Now(),
            Members:   ch.Members,
            Date:      time.Now().Format("2006-01-02"),
        })
    }

    return c.store.Shutdown()
}
```

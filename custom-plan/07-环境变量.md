# 环境变量参考

## 配置类环境变量

### 核心变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_CONFIG_LOCATION` | 配置文件路径 | `{DATA_PATH}/config.yaml` |
| `SOFT_SERVE_DATA_PATH` | 数据目录 | `data` (filestore 后端默认改为 `.`) |
| `SOFT_SERVE_NAME` | 服务器名称 | `Soft Serve` |
| `SOFT_SERVE_INITIAL_ADMIN_KEYS` | 初始管理员公钥 | (无) |

### SSH 配置

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_SSH_ENABLED` | SSH 服务开关 | `true` |
| `SOFT_SERVE_SSH_LISTEN_ADDR` | SSH 监听地址 | `:23231` |
| `SOFT_SERVE_SSH_PUBLIC_URL` | SSH 公开 URL | `ssh://localhost:23231` |
| `SOFT_SERVE_SSH_KEY_PATH` | SSH 主机密钥路径 | `{DATA_PATH}/ssh/soft_serve_host_ed25519` |
| `SOFT_SERVE_SSH_CLIENT_KEY_PATH` | SSH 客户端密钥路径 | `{DATA_PATH}/ssh/soft_serve_client_ed25519` |
| `SOFT_SERVE_SSH_MAX_TIMEOUT` | SSH 最大超时 (秒) | `0` (无限制) |
| `SOFT_SERVE_SSH_IDLE_TIMEOUT` | SSH 空闲超时 (秒) | `600` (10分钟) |

### HTTP 配置

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_HTTP_ENABLED` | HTTP 服务开关 | `true` |
| `SOFT_SERVE_HTTP_LISTEN_ADDR` | HTTP 监听地址 | `:23232` |
| `SOFT_SERVE_HTTP_PUBLIC_URL` | HTTP 公开 URL | `http://localhost:23232` |
| `SOFT_SERVE_HTTP_TLS_KEY_PATH` | TLS 私钥路径 | (空) |
| `SOFT_SERVE_HTTP_TLS_CERT_PATH` | TLS 证书路径 | (空) |
| `SOFT_SERVE_HTTP_CORS_ALLOWED_HEADERS` | CORS 允许的 Headers | `Accept,Accept-Language,...` |
| `SOFT_SERVE_HTTP_CORS_ALLOWED_ORIGINS` | CORS 允许的 Origins | `http://localhost:23232` |
| `SOFT_SERVE_HTTP_CORS_ALLOWED_METHODS` | CORS 允许的 Methods | `GET,HEAD,POST,PUT,OPTIONS` |

### Git Daemon 配置

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_GIT_ENABLED` | Git daemon 开关 | `true` |
| `SOFT_SERVE_GIT_LISTEN_ADDR` | Git daemon 监听地址 | `:9418` |
| `SOFT_SERVE_GIT_PUBLIC_URL` | Git daemon 公开 URL | `git://localhost` |
| `SOFT_SERVE_GIT_MAX_TIMEOUT` | 最大超时 (秒) | `0` (无限制) |
| `SOFT_SERVE_GIT_IDLE_TIMEOUT` | 空闲超时 (秒) | `3` |
| `SOFT_SERVE_GIT_MAX_CONNECTIONS` | 最大连接数 | `32` |

### Stats 配置

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_STATS_ENABLED` | Stats 服务开关 | `true` |
| `SOFT_SERVE_STATS_LISTEN_ADDR` | Stats 监听地址 | `localhost:23233` |

### 日志配置

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_LOG_FORMAT` | 日志格式 | `text` (`json`, `logfmt`) |
| `SOFT_SERVE_LOG_TIME_FORMAT` | 日志时间格式 | `2006-01-02 15:04:05` |

### 数据库配置 (仅 dbstore 后端)

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_DB_DRIVER` | 数据库驱动 | `sqlite` (`postgres`) |
| `SOFT_SERVE_DB_DATA_SOURCE` | 数据库连接字符串 | `soft-serve.db?_pragma=...` |

### LFS 配置

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_LFS_ENABLED` | LFS 开关 | `true` |
| `SOFT_SERVE_LFS_SSH_ENABLED` | LFS over SSH 开关 | `false` |

### Jobs 配置

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_JOBS_MIRROR_PULL` | 镜像拉取定时任务 | `@every 10m` |

### 路径配置 (仅 filestore 后端)

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SOFT_SERVE_USERS_PATH` | 用户目录 | `{DATA_PATH}/users` |

**固定路径 (不可通过环境变量配置):**

| 路径 | 默认值 |
|------|--------|
| SSH 密钥 | `{DATA_PATH}/ssh` |
| 日志 | `{DATA_PATH}/log` |
| LFS | `{DATA_PATH}/.lfs` |
| Admin 公钥 | `~/.ssh` |

## 运行时环境变量

以下变量在 Git hooks 执行时自动注入，可在 hook 脚本中使用：

| 变量 | 说明 |
|------|------|
| `SOFT_SERVE_BIN_PATH` | soft 可执行文件路径 |
| `SOFT_SERVE_REPO_NAME` | 当前仓库名称 |
| `SOFT_SERVE_REPO_PATH` | 当前仓库路径 |
| `SOFT_SERVE_LOG_PATH` | 日志文件路径 |
| `SOFT_SERVE_USERNAME` | 当前用户名 |
| `SOFT_SERVE_PUBLIC_KEY` | 当前用户公钥 |
| `SOFT_SERVE_HOST` | 主机名 |

### Hook 示例

```bash
#!/bin/bash
# .git/hooks/post-receive

echo "Repository: $SOFT_SERVE_REPO_NAME"
echo "Pushed by: $SOFT_SERVE_USERNAME"
echo "Repo path: $SOFT_SERVE_REPO_PATH"
```

## 配置优先级

```
环境变量 > 配置文件 > 默认值
```

### 示例

```bash
# 配置文件: config.yaml
ssh:
  listen_addr: ":2222"

# 环境变量覆盖
export SOFT_SERVE_SSH_LISTEN_ADDR=":3333"

# 最终使用: :3333
```

## 后端差异

| 环境变量 | FileStore | DBStore |
|----------|-----------|---------|
| `SOFT_SERVE_DATA_PATH` | 默认 `.` (当前目录) | 默认 `data` |
| `SOFT_SERVE_DB_*` | 忽略 | 使用 |
| `SOFT_SERVE_PATHS_*` | 使用 | 忽略 |

### FileStore 数据路径处理

```go
// pkg/store/file/store_filestore.go

func NewStore(cfg *config.Config) (store.Store, error) {
    // FileStore 覆盖默认数据路径
    if cfg.DataPath == "data" {
        // 如果是默认值，改为当前目录
        cfg.DataPath = "."
    }
    // ...
}
```
